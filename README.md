## 🔎 Multi-Agent Research Assistant

Why burn expensive AI credits on long research sessions when you can run a dedicated research workflow?

This project is a **Groq-powered multi-agent research assistant** built to make extended web research more efficient and affordable. Instead of depending on a single AI assistant for everything, it splits the work across specialized agents:

**Search → Read → Write → Critique → Result**

The Search Agent finds relevant sources, the Reader Agent extracts useful information, the Writer Agent builds the report, and the Critic Agent reviews it for gaps and weaknesses.

Built with **Groq, LangChain, Tavily, BeautifulSoup, and Streamlit**, this is a practical way to experiment with deep research workflows while **avoiding the need to burn through credits on every long research session**.
